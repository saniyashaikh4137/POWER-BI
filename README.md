# Food Sales Analysis - Power BI 📊

This is my very first Power BI project! In this project, I have analyzed food ordering data to understand the total quantity of food items ordered across different food types.

## 🛠️ Tools Used
* Power BI Desktop
* Page Formatting & Custom Tooltips
* Excel / CSV Data Source

## 📈 Key Insights from Visuals
* **Main Course** is the most ordered food category, reaching nearly 7K in total quantity.
* **Snacks** follow closely as the second most popular choice.
* Analyzed other categories like Dessert, Breakfast, Beverages, and Appetizers to find ordering trends.
